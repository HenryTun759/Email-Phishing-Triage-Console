# Contributing

Keep this lab easy to run with the Python standard library. Add a synthetic regression case for changes to parsing or scoring, document changed rule weights in `docs/METHODOLOGY.md`, and run `python3 -m unittest discover -s tests -v` before proposing changes.

Never commit real emails, credentials, tokens or live malicious attachments. Use `.example` / `example.org` domains and documentation IP ranges for fixtures. Maintain explicit separation between extracted evidence, unverified claims and analyst conclusions.
